# StoreDesk brand kit

## Canonical filenames

| File | Use |
|------|-----|
| `logo-mark.svg` / `logo-mark.jpg` | Hexagon + S mark |
| `logo-lockup-horizontal.svg` / `.jpg` | Mark + StoreDesk wordmark |
| `wordmark-horizontal.jpg` | Wordmark only |
| `app-icon.ico` | Desktop / package icon (32×32 source) |

Messy originals may remain for archival; prefer the names above in apps.
