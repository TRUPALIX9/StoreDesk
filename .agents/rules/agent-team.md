# Agent Team Rule (always active)

See full org chart, routing, and skills list: `.agents/AGENTS.md`

## Quick routing

- Multi-repo / unclear ownership → `eng-manager` first
- Architecture / contracts → `tech-lead`
- Visual redesign → `ui-ux-designer` (readonly) → implementer
- Electron UI → `frontend-electron`
- Worker API / Mongo → `backend-server`
- Flutter / mobile / Android Studio → `mobile-flutter`
- CI / test results → `qa-verifier`
- Docs / maps → `docs-scribe`

## Before every multi-step task

1. Check for an active Work Order in `docs/work-orders/`
2. Load the matching skill before editing
3. Write a Handoff when switching roles or pausing
